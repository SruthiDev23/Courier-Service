SRUTHI COURIER SERVICE WEBSITE

HOW TO RUN
1. Extract the ZIP file.
2. Open the sruthi_courier_service folder.
3. Double-click index.html to open it in Chrome, Edge or Firefox.
4. Internet is needed for Google Fonts and the online Unsplash images.

FILES
index.html - Website content and sections
style.css  - Responsive design and styling
script.js  - Mobile menu, demo tracking and form interactions

DEMO TRACKING ID: SRC123456

IMPORTANT
This is a front-end college-project demo. Tracking data is sample data. Booking,
contact, login and registration forms only validate and show demo messages; they
do not send data to a server and do not provide real authentication. Add a secure
backend, database and real courier API before using this commercially.

Update the sample phone, email and office address before presenting the project.
